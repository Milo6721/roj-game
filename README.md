# Roj

Neonowa gra akcji (survivor) w przeglądarce. Jeden plik HTML, bez instalacji.

**Granie:** otwórz `index.html` w przeglądarce (lub włącz GitHub Pages dla gałęzi `main`).

- Ruch: `WASD` / strzałki, unik: `Spacja`. Na telefonie: przeciągnij palcem, przycisk DASH robi unik.
- Broń strzela sama. Zbieraj kryształy, wybieraj ulepszenia (12 broni, 6 ulepszeń pasywnych), pokonuj strażników roju.
- 10 typów wrogów, okrążenia, bossowie ze zmiennymi atakami.
- Klawisz `~` otwiera konsolę (`help`).
